# Hyperline Integration

## Hyperline Integration

Integrating Hyperline with Sphere enables transaction data import and live tax calculation within Hyperline.

This guide provides step-by-step instructions on generating an API key in Hyperline, linking it to Sphere for a secure integration, and selecting Sphere as the tax engine in Hyperline.

#### Part 1: Configure Data Synchronization from Hyperline to Sphere

1. In the Sphere account, click on the Connect button on the Hyperline tile.

<figure><img src="../../../.gitbook/assets/image (38).png" alt=""><figcaption></figcaption></figure>

2. In another window, open your Hyperline dashboard, navigate to **Settings**, and click **API** under **Developers**.

<figure><img src="../../../.gitbook/assets/image (39).png" alt=""><figcaption></figcaption></figure>

3. Click **Create API key**, give the key a name (for example, Sphere), leave **Read** and **Write** access on, and click **Create API key**. Copy the key, since Hyperline only shows it once.

<figure><img src="../../../.gitbook/assets/image (40).png" alt=""><figcaption></figcaption></figure>

4. Go back to your Sphere dashboard, paste the key into **Hyperline API key**, and click **Next**. Sphere checks the key with Hyperline before saving the connection.

<figure><img src="../../../.gitbook/assets/image (41).png" alt=""><figcaption></figcaption></figure>

5. On the next step, you will be prompted to generate a Sphere API key. Save this API key for Part 2 below.

<figure><img src="../../../.gitbook/assets/image (42).png" alt=""><figcaption></figcaption></figure>



For more detail on the Hyperline side, see Hyperline's [Sphere integration guide](https://docs.hyperline.co/integrations/sphere).
