# Example Billing Flows with Stripe

You have three options:&#x20;

* **Sphere-hosted Checkout** - Sphere hosts the checkout page and calculates tax for you, in a single API call. The simplest option.&#x20;
* **Stripe Elements** - build a custom checkout in your own page for greater flexibility, with Sphere calculating taxes.&#x20;
* **Stripe-hosted Checkout** - let Stripe manage the checkout experience, with Sphere calculating taxes.&#x20;

The Stripe Elements and Stripe-hosted Checkout flows use the Sphere Tax Calculation API to apply accurate tax rates during checkout. Sphere-hosted Checkout handles tax for you.
